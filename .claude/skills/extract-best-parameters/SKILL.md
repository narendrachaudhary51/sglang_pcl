---
name: extract-best-parameters
description: 'This skill is for extracting the best tiling/blocking parameters for each operation in the model. 
 It will run and read the CSV files generated by the bench-cpu-gemms and bench-cpu-moe skill and extract the best parameters 
 for each operation based on the performance in TFLOPs and bandwidth in GB/s.' 
---

# Step 1: Run the bench-cpu-gemms and bench-cpu-moe skill for the given model and precision

- Run bench-cpu-gemms skill for the given model and precision. Do not skip the plot creation part.
- Run bench-cpu-moe skill for the given model and precision. Do not skip the plot creation part

# Step 2: Read the benchmark results for bench-cpu-gemms skill

- Accept model_name as input parameter. This is the name of the model for which we want to extract the best parameters.
- Read the benchmark results from the skills/bench-cpu-gemms/references/${model_name}/gemm_benchmark_results_*.csv files generated by the bench-cpu-gemms skill.
- There are seperate CSV files for each TILE size configuration. Each CSV file contains the performance results for each GEMM operation in the model for different M, N, K parameters and precisions.

# Step 3: Extract the best parameters for each GEMM operation

- For each GEMM operation and batch size M for a model, extract the best Tiling parameters based upon the time in ms.
- Write the best parameters for each GEMM operation into a bench-cpu-gemms/references/${model_name}/best_parameters.csv file. This file will contain the following columns:
  - GEMM operation shape (M, N, K)
  - Best TILE_M
  - Best TILE_N
  - Best TILE_K
  - Precision
  - time in ms
  - Performance in TFLOPs
  - Bandwidth in GB/s
- Do not write everthing into the best_parameters.csv file. Only write the best parameters for each GEMM operation and batch size M.

# Step 4: Read the benchmark results for bench-cpu-moe skill

- Accept model_name as input parameter. This is the name of the model for which we want to extract the best parameters.
- Read the benchmark results from the skills/bench-cpu-moe/references/${model_name}/moe_benchmark_results_*.csv files generated by the bench-cpu-moe skill.
- There are seperate CSV files for each TILE size configuration. Each CSV file contains the performance results for each MoE operation in the model for different M, N, K parameters and precisions.

# Step 5: Extract the best parameters for each MoE operation
- For each MoE operation and batch size M for a model, extract the best Tiling parameters based upon the time in ms.
- Write the best parameters for each MoE operation into a bench-cpu-moe/references/${model_name}/best_parameters.csv file. This file will contain the following columns:
  - MoE operation shape (M, N, K)
  - Best TILE_M
  - Best TILE_N
  - Best TILE_K
  - Precision
  - time in ms
  - Performance in TFLOPs
  - Bandwidth in GB/s
- Do not write everthing into the best_parameters.csv file. Only write the best parameters for each MoE operation and batch size M.


# Step 6: Final Analysis and output

- Read the best parameters for each GEMM and MoE operation from the references/${model_name}/best_parameters.csv file.
- Find one set of parameters that give the best performance in TFLOPs and bandwidth in GB/s for both gemm and moe operations.
- Write the best parameters for the model into a extract-best-parameters/references/${model_name}/final_best_parameters.csv
