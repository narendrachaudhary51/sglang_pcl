description: 'This skill is for extracting the best tiling/blocking parameters for each GEMM operation in the model. It will read the CSV files generated by the bench-cpu-gemms skill and extract the best parameters for each GEMM operation based on the performance in TFLOPs and bandwidth in GB/s.' 
---

# Step 1: Read the benchmark results

- Accept model_name as input parameter. This is the name of the model for which we want to extract the best parameters.
- Read the benchmark results from the $HOME/sglang_pcl/skill_outputs/model_name/gemm_benchmark_results_*.csv files generated by the bench-cpu-gemms skill.
- There are seperate CSV files for each TILE size configuration. Each CSV file contains the performance results for each GEMM operation in the model for different M, N, K parameters and precisions.

# Step 2: Extract the best parameters for each GEMM operation

- For each GEMM operation and batch size M for a model, extract the best Tiling parameters based upon the time in ms.
- Write the best parameters for each GEMM operation into a references/best_parameters.csv file. This file will contain the following columns:
  - GEMM operation shape (M, N, K)
  - Best TILE_M
  - Best TILE_N
  - Best TILE_K
  - Precision
  - time in ms
  - Performance in TFLOPs
  - Bandwidth in GB/s
- Do not write everthing into the best_parameters.csv file. Only write the best parameters for each GEMM operation and batch size M.
